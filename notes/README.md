# Notes

What this deployment adds to the protocol's documents, in its own words. Each
file fills one `{{note:<name>}}` slot of a template in `templates/`; a slot
with no file renders as nothing. The settings' `notes` names this directory.
After changing one, run `npm run docs`.

| File | Where it goes |
| --- | --- |
| `where-the-work-is.md` | PROTOCOL.md, "Where the work is": the tracker's history here |
| `repositories.md` | PROTOCOL.md, "The repositories": what each repository is |
| `acceptance.md` | PROTOCOL.md, "PM ticks": what an item's Acceptance must also cite |
| `sweep-jobs.md` | PROTOCOL.md, "What watches the agents": where the sweep runs |
| `paging.md` | PROTOCOL.md, "What watches the agents": whether pages are sent |
